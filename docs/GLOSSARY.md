# Aegle 界面系统

本术语表统一讨论 Aegle 界面时使用的名称。

## Language

**保留模式界面（Retained UI）**：
创建后持续存在，直到被修改或销毁的界面；一次绘制完成不意味着界面描述或交互状态消失。
_Avoid_: 将保留模式等同于声明式语法

**界面标记语言（UI Markup）**：
用于表达界面结构、属性与组件使用方式的语言，是本项目优先面向界面作者的编写入口。
_Avoid_: 将标记语言统称为脚本运行时

**命令式界面 API（Imperative UI API）**：
以明确的创建、修改等命令表达界面操作的 Rust 接口，是标记语言之外的界面编写入口。
_Avoid_: 将命令式等同于立即模式

**组件库（Component Library）**：
供应用作者复用的一组界面组件，可承载一套视觉风格与交互约定，例如 MD3 风格的组件。
_Avoid_: 将组件库等同于绘制后端

**默认组件库（Default Component Library）**：
框架提供的、采用跨平台一致中性极简外观的一组开箱即用的界面组件。
_Avoid_: 将默认组件库等同于不可替换的核心

**无障碍语义（Accessibility Semantics）**：
辅助技术理解和操作界面所需的控件含义，包括角色、名称、值、状态、关系和可执行动作。
_Avoid_: 将无障碍语义等同于屏幕像素或控件外观

**控件树（Control Tree）**：
界面中控件及其逻辑包含关系构成的可检查结构，不要求每个控件都对应一个平台原生视图。
_Avoid_: 将控件树等同于原生视图树

**无障碍语义树（Accessibility Tree）**：
向系统辅助技术呈现的可感知、可操作元素及其关系；可省略装饰元素，也可合并一个控件的内部组成。
_Avoid_: 将语义树等同于绘制元素清单

**主题（Theme）**：
可供界面及组件共享的一组视觉规则与取值，用于形成一致且可调整的外观。
_Avoid_: 将主题等同于特定组件库或操作系统皮肤

**界面动画（UI Animation）**：
界面随时间呈现的连续变化，可表达状态转换、反馈或内容运动。
_Avoid_: 将界面动画等同于应用永久逐帧重建界面

**逻辑目标值（Target Value）**：
属性经过默认值、主题、本地值或绑定规则解析后应到达的值。
_Avoid_: 将目标值等同于动画中的当前呈现值

**呈现值（Presented Value）**：
当前帧实际用于绘制和几何交互的属性值，可暂时由动画覆盖。
_Avoid_: 将呈现值作为独立业务状态

**控件类型（Control Kind）**：
控件库为一种控件声明的静态描述：默认皮肤、接受的样式组与是否为布局容器；内置与第三方控件使用同一形式，决定外观的默认来源。
_Avoid_: 将控件类型等同于 Rust 类型或无障碍角色

**皮肤（Skin）**：
由主题与视觉状态计算外观的纯函数；作用于单个节点、子树中的某一控件类型，或作为类型的默认外观。
_Avoid_: 将皮肤等同于主题或局部样式

**装饰器（Decorator）**：
挂在已有控件上的附加绘制，在其背景之下或内容之上录制图元并观察它收到的输入，不改变控件行为。
_Avoid_: 将装饰器等同于叠加在控件上方的另一个控件

**标记元素（Markup Element）**：
标记中可写的一种节点及其规格：名称、布局、样式组、属性、事件与 `self` 字段，由控件库用 `element!` 声明；内置元素与第三方元素使用同一契约。
_Avoid_: 将标记元素等同于控件类型或标记组件（`component`）
