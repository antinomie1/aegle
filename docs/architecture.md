# 整体架构与运行契约

状态：v0.1 设计基线，2026-10-05。用户已授权剩余决定由设计者完成。本文定义设计，不声称已实现或测量。对应 R01–R23。

## 总体决定

采用 Rust 2024，目标 MSRV 1.88；保留模式、单 UI 主线程、显式命令更新、Taffy 布局。主要编写入口是编译型标记语言，可选运行时加载；Rust 命令式入口具有同样的控件行为。Linux/Windows 使用 Vulkan，macOS 使用原生 Metal；无 GPU 设备使用独立软件 renderer，共用 scene 和文字管线。

核心只处理身份、逻辑包含关系、属性变化、事件、焦点与生命周期。布局、文本、绘制、平台、无障碍、主题和动画分别作为可组合模块。便捷应用层负责把它们连接起来；任何底层模块都不反向依赖便捷入口。

不引入 ECS、虚拟 DOM、通用插件 ABI、后台常驻调试服务器、全局异步运行时或通用脚本 VM。独立模块不等于每个结构体一个 crate；实际打包与依赖见[模块](modules.md)。

## 状态、身份与存储

- `NodeId` 为 32 位槽位加 32 位代数，代数耗尽的槽位退休，不回绕复用。ID 只在所属 UI 内有效。
- 节点放在集中槽位表中；记录父节点索引、可按位置访问的紧凑子索引数组、状态位及必要属性。叶节点的子数组不分配堆内存，避免链式子列表让 Taffy 索引访问退化。布局、主题覆盖、文本、监听器等大数据按需放入旁表，不让每个空节点携带全部能力。
- `App` 持有 UI。公开控件句柄包含弱 UI 引用和节点 ID，克隆句柄不克隆控件。句柄为 `!Send + !Sync`；丢弃句柄不删除控件，销毁由父树或显式 `remove()` 管理。
- 每个属性只有一个逻辑来源。布局结果、绘制记录、主题解析值和无障碍节点是派生数据，不作为另一个可任意写入的真相来源。
- 文本、主题、动画模块不直接拥有完整控件树；应用层将节点 ID 与各模块资源对应。各模块也可在其他宿主中独立使用。

## 不同树的关系

逻辑控件树用于包含关系与生命周期；Taffy 通过低层树接口读取该拓扑，布局适配只维护样式、计算缓存和结果，不再创建一份 TaffyTree 所有权树。文本测量通过纯测量回调提供，计算期间不能触发应用事件。

绘制记录按控件维护，只重建外观失效部分；一个按钮可输出背景、图标、文字等多条命令。无障碍语义树可以合并这些装饰元素，并按需要展开文本范围。AccessKit 自身的语义树缓存属于真实额外内存，必须核算。

弹出层可以在单独绘制层呈现，但保留逻辑所有者。焦点顺序和无障碍顺序由逻辑与语义关系确定，不从 GPU 命令次序推断。

## 一次更新的顺序

1. 平台将输入或辅助技术动作转换为规范事件；处理坐标和文本范围单位转换。
2. 按命中、焦点或目标 ID 路由事件，更新控件行为；调用应用处理器前释放内部树借用。
3. 处理器执行短暂、显式的属性修改；同一事件轮次收集脏标记，不为每个 setter 立即绘制。
4. 按受影响依赖更新标记绑定与主题值，推进当前活动动画，得到呈现属性。
5. 对布局失效的区域调用 Taffy；有约束变化的文本重新测量；更新命中几何、候选窗位置和语义几何。
6. 提交语义差量和必要平台状态，刷新失效绘制记录；仅有像素变化时请求呈现。
7. 没有待处理事件、动画或显式定时任务时，交还平台等待机制。

这里的次序是可观察行为契约，不要求所有工作都通过抽象消息总线。属性仅改变语义时无需请求 GPU 帧；颜色变化不重新排版；字体或文字变化可能同时影响布局、绘制与语义。

## 事件与线程

UI、窗口和焦点由主线程拥有。后台工作通过 `UiProxy::post` 投递可发送的数据或闭包，在 UI 线程验证目标仍存活后处理；核心不依赖 Tokio。可由应用接入任意任务系统，模块内部的必要线程仍分别计量。

指针和键盘按根到目标捕获、目标处理、目标到根冒泡；事件可停止传播或阻止默认动作。行为模块提供 activate、toggle、edit 等语义动作，指针、键盘和辅助技术共用这些入口。重复按键不等于重复文本提交。

回调不得在树借用期间执行；`FnMut` 处理器在调用前暂时移出存储，结束后仅在节点与注册版本仍有效时放回。回调内增删节点和替换监听器允许，但不会递归分发新事件，新事件排到当前回调之后。

处理器返回错误时停止该处理器并交给应用错误入口，保留此前合法修改；事件批处理不是事务回滚。批量加载界面的原子替换规则见[标记语言](markup.md)。

## 属性来源与失效

基础目标值依次取：组件默认值、主题与状态样式、本地值。绑定占用本地值来源；显式 setter 会移除该属性的现有绑定，`bind()` 则替换本地常量。由此避免两个写者暗中争用同一个属性。

动画只覆盖呈现值，不偷偷改写目标值。新目标从当前呈现值开始过渡。颜色/透明度变化只标记绘制，尺寸/字体变化标记布局与相关文本，交互状态变化标记行为和语义，几何变化同步命中、IME 与无障碍。属性描述符声明这些影响，组件作者不手工猜测更新范围。

绑定依赖环在建立时拒绝；一次外部事件内的反复状态振荡最多传播 64 轮，随后报告带属性链的 UpdateCycle 错误并停止本轮传播，避免界面挂死。正常更新按依赖顺序执行，64 轮不是正常路径的每帧成本。

## 销毁与错误

移除节点时先标记不可再接受事件，结束其编辑会话和指针捕获、迁移焦点、取消动画与任务订阅，再移除语义关系与子树，最后回收槽位。失效句柄的公开操作返回 `DeadHandle`，不导致 use-after-free 或静默修改后来复用的节点。

字体缺失、格式不支持、IME 协议缺失、设备丢失和标记错误都是结构化错误，带模块、节点/资源和原因。资源创建失败清理已创建部分。GPU 设备丢失使对应窗口停止提交并报告 `DeviceLost`；首版不做隐藏的跨后端自动重建。

## 全系统共同不变量

| 场景 | 必须成立的结果 |
| --- | --- |
| IME 预编辑中切换主题 | 不重建编辑器；已提交值、预编辑和选择保持区分 |
| 动画移动/缩放输入框 | 命中、焦点提示、可取得的语义位置和候选窗使用同一呈现变换 |
| 辅助技术激活自定义按钮 | 经过与键盘/指针相同的行为及禁用检查 |
| 修改文本或字体 | 文字测量、Taffy、绘制和语义范围按规定更新 |
| 销毁仍在动画的控件 | 不再收到动画完成回调或平台动作；相关资源最终释放 |
| 替换组件库 | 不需要重写平台 IME、文字成形或无障碍协议 |

具体 API、模块和资源预算分别见 [Rust API](rust-api.md)、[模块](modules.md)、[资源](resources.md)。
