# 整体架构与运行契约

Aegle 是基于 Rust 2024 的保留模式、单 UI 主线程、可组合模块 GUI 框架。界面优先通过标记语言或命令式 Rust 编写；核心只处理身份、包含关系、事件路由与生命周期，布局、文本、绘制、无障碍与主题动画均为可独立组合的底层模块。

---

## 一、 状态、身份与存储

* **节点标识 (`NodeId`)**：32 位槽位索引 + 32 位代数。代数耗尽的槽位退休不复用，ID 仅在所属 UI 树内有效。
* **集中存储**：节点拓扑存放在槽位表扁平数组中，记录父索引与紧凑子索引数组。布局约束、样式覆盖、文本内容与事件监听器存放在稀疏旁表中，空节点不携带多余开销。
* **弱句柄语义**：公开句柄（如 `Button`、`TextField`、`Window`）仅持有弱引用和 ID，克隆句柄不克隆控件，丢弃句柄不删除控件。关闭窗口或显式 `remove()` 销毁控件树，已失效句柄的调用安全触发 `UiError::DeadHandle` panic，不导致 use-after-free。
* **单一状态来源**：布局坐标、绘制命令、主题解析结果与无障碍树均为派生数据，逻辑状态在树与应用数据中唯一确定。

---

## 二、 树拓扑与协同模型

1. **逻辑控件树**：管理包含关系与生命周期。
2. **布局适配树**：Taffy 直接通过低层树接口读取逻辑拓扑，只维护样式与计算缓存，不创建第二份所有权树。虚拟 `contents` 节点（类似 CSS `display: contents`）让子节点直接参与外层 flex 或 grid 布局。
3. **绘制场景 (`Scene`)**：按控件维护局部绘制命令，刷新时只重构外观失效部分。
4. **无障碍语义树**：合并控件内部装饰性元素，按需展开文字选择范围，独立提交系统适配器。
5. **滚动视口与弹出层**：
   * `ScrollView` 保留子树拓扑，累加祖先变换与视口裁剪矩形，仅滚动时复用原有绘制记录与文字成形。
   * 弹出层（`Popup`/`Dialog`/`Drawer`）在独立图层渲染，但保留逻辑所有权与焦点链。

## 三、 更新周期（事件循环管线）

每一次事件轮次按以下确定顺序推进：

```
[1. 平台原生事件] 
      ↓ （坐标与输入映射）
[2. 事件路由分发] ── (捕获阶段: 根 → 目标 | 冒泡阶段: 目标 → 根)
      ↓ （释放内部树借用）
[3. 应用回调执行] ── (属性修改打脏标记，推迟到批处理末尾生效)
      ↓
[4. 呈现属性更新] ── (计算主题 Token 覆盖与动画过渡采样)
      ↓
[5. 布局与文本计算] ─ (对失效区域调用 Taffy，重新成形有约束变化的文本)
      ↓
[6. 绘制刷新与提交] ─ (更新失效 Scene，提交语义差量，向平台请求呈现)
      ↓
[7. 空闲等待] ────── (无活动动画或待处理事件时，交还平台阻塞等待)
```

---

## 四、 线程模型与输入路由

* **主线程独占 UI**：UI 树、窗口句柄与焦点仅在主线程操作。
* **跨线程通信 (`UiProxy`)**：后台线程通过有界队列（上限 1024）向 UI 线程发送消息，由绑定的处理器在所有内部借用之外安全消费。
* **输入事件路径**：
  * 指针/按键沿祖先链分发：`on_input_capture`（根→目标）先执行，`on_input`（目标→根）后执行。
  * 处理器支持 `stop_propagation()` 终止路径，支持 `prevent_default()` 拦截默认行为（如按键导航或点击）。
* **处理器生命周期**：所有 `on_*` 返回可注销的 `Subscription`；处理器在树借用之外运行，允许增删控件或关闭窗口，产生的后续操作排入下一轮执行，杜绝递归分发。

## 五、 属性来源与失效管道

属性取值优先级依次为：**本地显式赋值 > 状态样式 / 主题 Token > 组件默认值**。动画仅覆盖呈现值（`presented`），不改写逻辑目标值。

| 变更类型 | 触发的失效通道 | 最终动作 |
|---|---|---|
| **颜色 / 透明度 / 阴影** | `Dirty::PAINT` | 仅刷新 Scene 绘制命令并提交重绘 |
| **尺寸 / 外边距 / 字号** | `Dirty::LAYOUT` | 重新调用 Taffy 计算与文本排版，同步更新几何 |
| **控件结构增删 / 显隐** | `Dirty::STRUCTURE` | 重建子节点列表、更新命中树与焦点顺序 |
| **控件文本内容修改** | `Dirty::LAYOUT` + `Dirty::SEMANTICS` | 段落增量成形，更新布局，导出无障碍差量 |

## 六、 全系统共同不变量

| 场景 | 必须保证的行为 |
|---|---|
| **IME 预编辑中切换主题** | 不重建编辑器；已提交文字、预编辑内容与选区边界严格保持区分 |
| **动画缩放或平移输入框** | 命中检测、焦点高亮、无障碍几何与输入法候选窗口使用同一呈现变换 |
| **无障碍辅助技术激活控件** | 走与物理键盘/鼠标相同的行为分发路径与禁用状态检查 |
| **销毁正在播放动画的控件** | 安全取消动画与任务订阅，立即注销弱句柄，资源最终释放 |
| **替换组件库** | 不需要重写平台 IME、文字成形管线或无障碍协议适配 |
