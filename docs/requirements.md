# 需求、架构决策与验收标准

记录 Aegle 的核心需求（R01–R23）、关键架构决策以及工程验收边界。

---

## 一、 核心需求表

| 编号 | 维度 | 规范要求 |
|---|---|---|
| **R01** | 语言标准 | Rust 2024 edition，目标 MSRV 1.88。 |
| **R02** | 界面模型 | 保留模式（Retained Mode）；状态跨事件和帧持久存在。 |
| **R03** | 布局引擎 | Taffy 0.14.0，直接树适配，默认 Flexbox/Block，可选 Grid。 |
| **R04** | 资源优先级 | 交互延迟达标后，优先降低空闲 CPU/唤醒、常驻 RAM、包体体积，最后考虑超额帧率。 |
| **R05** | 模块拆分 | 模块独立可用；各层单向依赖，禁止过度抽象或仅做转发的胶水 Crate。 |
| **R06** | 渲染后端 | 多渲染器互斥编入：CPU（tiny-skia 默认，cairo 可选）、Vulkan 1.1 与通用 wgpu。 |
| **R07** | 平台支持 | Linux（默认 SDL3，可选原生 Wayland）、Windows（Win32）、macOS（AppKit）。 |
| **R08** | 标记编写 | 简洁花括号标记语言；支持编译期 `ui!` 宏展开，以及可选的运行时动态解释加载。 |
| **R09** | Rust API | 创建一次，弱句柄显式修改，事件驱动命令式更新；不采用每帧重述界面的即时模式。 |
| **R10** | 极简入口 | 完整 Hello World 程序在 10 行以内（包含初始化与事件循环）。 |
| **R11** | 使用场景 | 覆盖三平台标准窗口；Linux 原生客户端额外支持 wlr layer-shell 面板与覆盖层。 |
| **R12** | 组件扩展 | 第三方可通过实现开放的 `Control` trait 和 `Hooks` 编写高度可复用控件库。 |
| **R13** | 文本排版 | 原生支持中日韩（CJK）；排版与字形优先委托操作系统文字栈，避免静态内嵌大体积字形。 |
| **R14** | 原生输入 | 原生集成平台输入法（Linux SDL3 文本输入 / Wayland text-input-v3、Windows TSF、macOS NSTextInputClient）。 |
| **R15** | 发布体积 | 运行时尽量依赖系统已安装库（SDL3、Pango、FreeType 等），release 构建尽可能极小。 |
| **R16** | 验证原则 | 编写关键边界与集成场景测试，不为每个简单 getter/setter 堆叠重复测试。 |
| **R17** | 无障碍 | 导出完整系统语义树（角色、名称、值、焦点、动作）；通过 AccessKit 按需接入目标系统适配器。 |
| **R18** | 默认组件 | 跨平台一致的中性极简外观（类 Metro 风格），适配系统深浅色与高对比偏好。 |
| **R19** | 主题系统 | 原生有类型 Token（颜色、尺寸、字体、阴影）与局部稀疏覆盖，无需额外第三方库。 |
| **R20** | 动画系统 | 原生提供补间（Transition）与关键帧动画，支持阻尼弹簧曲线，空闲无多余唤醒。 |
| **R21** | 跨模块一致 | 布局、文本、绘制、无障碍与主题动画共用统一的几何、呈现值与失效管道。 |
| **R22** | 文档规范 | 保持事实性与一致性；不把未验证或计划中的目标当作已实现证据。 |
| **R23** | 绘制能力 | 基础矩形、圆角、边框、文字、图像、解析阴影、渐变填充，以及离屏组透明度与背景模糊。 |

## 二、 关键架构决策总结

* **单 UI 线程模型**：UI 树、焦点与窗口调度由主线程专有；后台工作通过 `UiProxy` 投递至队列并在借用外安全处理。
* **分词无内置词典**：中日韩泰分词直接使用宿主系统的 ICU 或 `CFStringTokenizer` 动态探测，找不到时静默关闭分词移动，不回退到粗糙近似算法。
* **单一渲染器构建**：互斥启用渲染器，杜绝在二进制中打包应用永远无法切换的多余图形代码。
* **系统文字栈优先**：Linux 使用 Pango/FreeType，Windows 使用 DirectWrite，macOS 使用 CoreText；Parley 降级为 opt-in 回退。
* **平台按需适配**：Linux 提供高兼容、极小包体的 `sdl3`（默认），以及面向专业桌面 shell 的 `wayland` 客户端。

---

## 三、 关键验收边界

1. **行数与入口**：`hello` 示例保持在 10 行以内完成初始化、开窗、文本排版与事件循环启动。
2. **多控件与文本压力**：100 控件 CJK 场景在静止状态下保持零周期性唤醒，内存缓存不随字符种类无限膨胀。
3. **输入法完整周期**：在预编辑期间切换主题、动画推进或焦点转移时，不丢失提交值，候选框矩形几何正确。
4. **生命周期与失效安全性**：删除正在运行动画或挂载监听器的控件，其弱句柄安全失效（`DeadHandle`），无 use-after-free 或内存泄漏。
5. **真实平台端到端**：覆盖 Wayland/Win32/macOS 真实窗口呈现、输入传递与无障碍读写。
